    • 10분 안에 같은 분석이 돌고 있으면 그 결과를 돌려줌

  6. 6

② AI 대화

POST /api/admin/ai-reports/{id} · 제한 90초
  1. 1

    브라우저서버질문 전송 · 요청 확인

    • 보내는 값: 질문 + 지금 보는 슬라이드 번호
    • 내 리포트인지, ready/confirmed인지, 2,000자 이하인지
  2. 2

    코드맥락 구성

    • 시스템: 지침 + 대화 자료 (분석 결과·질문 목록 평문, 1시간 캐시)
    • 최근 대화 20개 + "(지금 보는 슬라이드: N)" + 질문
  3. 3

    코드poppler지목한 슬라이드 먼저 첨부

    • "2페이지", "3번 슬라이드", "슬라이드 4", "이 슬라이드"를 찾음 (최대 3장)
    • 찾으면 그 쪽을 이미지·글자·PIN 위치로 만들어 질문 앞에 붙임
    • 원본은 서버 디스크 캐시, 강사 권한으로 다시 확인
  4. 4

    Claude 스트리밍답변 작성

    • 글자가 오는 대로 화면에 이어 씀
    • 요약·경향·개선 제안 질문 → 분석 결과로 답함
    • 위치·그림·표·수치 질문 → 반드시 슬라이드를 보고 답함
    슬라이드가 더 필요하면: view_slides 도구
    1. Claude가 슬라이드 번호 요청 (최대 3장)
    2. 서버가 그 쪽만 이미지·글자·PIN 위치로 만들어 돌려줌
    3. 다시 호출해 이어서 답함 (한 답변에 최대 2번)
  5. 5

    브라우저표시

    • 평문 말풍선 · **굵게**만 굵은 글씨로 렌더링
    • 질문 번호·픽셀 좌표는 답에 쓰지 않고 요소 이름으로 말함
  6. 6

    DB저장

    • 답이 끝까지 온 경우에만 대화 기록 저장

    끊김·중단·거부: 저장하지 않고 입력창에 질문 복원
