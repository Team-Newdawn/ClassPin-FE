# ClassPin AI 강사 리포트 — 추가 기능과 실험

기존 ClassPin을 복제해 진행한 로컬 실험입니다. 운영 서비스에는 배포하지 않았습니다.

## 추가한 기능

- **강사 리포트:** 핵심요약·질문 분포·범주별 원그래프·혼란 지점·개선 제안과 근거 표시.
- **모델별 결과 선택:** 같은 리포트 화면에서 OCR·문맥 모델 조합별 저장 결과 비교.
- **분석 처리:** OCR → 영역 분할 → PIN 좌표 연결 → 문맥 해석 → 리포트 생성·조회 API와 워커.
- **로컬 자동 로그인:** 로그인 화면을 생략하고 로컬 강사 계정으로 자동 인증합니다. 개발 모드·로컬 주소·로컬 Supabase에서만 동작하며 운영 빌드에서는 비활성화됩니다. 인증 자체를 제거한 것은 아닙니다.

## 진행한 실험

| 실험 | 방법 | 확인한 점 |
|---|---|---|
| 1. 규칙 기반 시제품 | Tesseract → OCR 줄 단위 박스(페이지당 최대 12줄) → PIN 좌표 연결 → 키워드·통계 템플릿 | 리포트 UI·흐름 검증. LLM 의미 분석은 아님 |
| 2. 모델 비교 | OCR + Layout + 문맥 분석 방법을 고정하고 모델 하나씩 교체 | 글자 인식·영역 검출·질문 의도·시간·가정 비용 비교 |

| 역할 | 비교 모델 | 표본 평가 결과 |
|---|---|---|
| OCR: 글자 읽기 | Tesseract / EasyOCR / 한국어 PP-OCRv5 | 문자 오류율 35.9% / 2.8% / **0.0%** |
| Layout: 영역 구분 | PP-DocLayoutV3 / PP-DocLayout-S / Florence-2 | 부분 정답 일치 **7/8** / 2/8 / 0/8 |
| LLM: 문맥 해석 | Qwen3 4B / Qwen3 1.7B / Granite 3.3 2B | 임시 의도 라벨 일치 **16/17** / 2/17 / 8/17 |

**잠정 추천:** PP-OCRv5 + PP-DocLayoutV3 + Qwen3 4B. 15페이지·17 PIN에 약 **11분 30초**. 한국어·문서 적합성, 로컬 자원 사용량, 상용 라이선스 검토 가능성을 기준으로 후보를 선정했습니다.

> 단일 PDF·후보별 1회·CPU 4스레드 실험입니다. OCR은 24문구, 영역은 8개 부분 정답, 의도는 비블라인드 임시 라벨 기준으로 전체 정확도를 뜻하지 않습니다. S·Florence는 영역 분석 후 리포트 단계에서 제외했습니다.

## 현재 한계·공유 범위

- 모델별 핵심요약은 아직 공통 검사 안내문입니다. 세부 PIN 대상 구분과 근거 없는 해석도 개선이 필요합니다.
- Grounding DINO·SAM은 다음 비교 후보이며 아직 실험하지 않았습니다.
- 서비스 소스만 공유합니다. **원본 자료·분석 결과·DB·모델 가중치·실제 환경변수는 제외**되어, 다른 PC에서 같은 화면을 보려면 로컬 설정과 데이터가 별도로 필요합니다.
