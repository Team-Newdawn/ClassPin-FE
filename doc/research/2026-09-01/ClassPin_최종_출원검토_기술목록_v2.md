# ClassPin 최종 출원 검토 기술 목록 v2

작성일: 2026-09-01

이 문서는 2026-08-31 검토안의 CP-04 `자료 개정판과 측정조건을 검증하는 강의 개선·학습 변화 비교`를 기각하고, 현재 ClassPin의 실제 제품 방향과 운영 DB 구조에 맞는 새 후보로 교체한다. ClassPin은 강의자료를 플랫폼 안에서 편집하거나 개정판으로 관리하는 제품이 아니므로 자료 개정 비교를 발명의 전제로 삼지 않는다.

여기서 `최종 후보`는 변리사에게 발명 상담과 정밀 선행기술조사를 의뢰할 기술 목록이다. 등록 가능성이나 타인 권리 비침해를 확정하는 법률 의견은 아니다.

## 2. 새 CP-04를 한 문장으로 설명하면

질문이 많이 모였다는 이유만으로 폴더 전체의 문제라고 말하지 않고, 분석 범위가 커질 때마다 독립 근거의 단위를 `질문 → 슬라이드 → 강의자료`로 바꾸어 검증한 뒤, 하위 범위를 통과한 주장과 코드로 계산한 수치만 상위 AI 리포트에 공급하는 방법이다.

초등학생에게 설명하면 다음과 같다.

- 한 슬라이드의 같은 부분에 비슷한 질문이 두 개 있으면 `이 슬라이드의 반복 신호`가 될 수 있다.
- 같은 문제가 서로 다른 슬라이드에서도 확인되면 `이 강의자료에서 반복되는 문제`로 올릴 수 있다.
- 같은 문제가 서로 다른 강의자료에서도 확인되면 `이 폴더에서 반복되는 문제`로 올릴 수 있다.
- 한 슬라이드에 질문이 100개 있어도 그것만으로 `폴더 전체가 모두 어렵다`고 쓰지는 못한다.
- AI는 아래 단계에서 검증된 근거 카드를 위 단계에서 다시 마음대로 해석하지 못한다.

## 3. 왜 이 처리가 필요한가

2026-09-01 운영 DB의 식별정보 없는 집계는 다음과 같다.

- 자료 45개, 슬라이드 425개, 질문 936개다.
- 질문이 있는 자료는 28개이고, 질문이 있는 슬라이드는 52개다.
- 한 슬라이드의 질문은 최대 111개다.
- 폴더는 3개이며 자료 수 중앙값은 3개, 최대 13개다.
- 어떤 폴더는 질문이 한 자료에 100% 몰려 있다.
- 질문 상태는 미답변 923개, 답변됨 3개, 해결됨 10개이고 실제 답변 레코드가 연결된 질문은 8개다.

이 분포에서 단순 합계, 자료별 비율의 평균 또는 AI 자유 요약을 사용하면 다음 오류가 생긴다.

1. 한 자료의 대량 질문을 폴더 전체의 공통 문제로 확대한다.
2. 질문이 없는 자료를 분석 대상에서 사라지게 만들어 폴더 대표성을 과장한다.
3. 서로 다른 분모의 비율을 평균하여 실제 전체 비율과 다른 수치를 만든다.
4. 같은 질문의 공감과 답변을 독립된 여러 근거처럼 중복 계산한다.
5. 위치가 다른 슬라이드의 좌표를 직접 합쳐 의미 없는 폴더 공간 지도를 만든다.
6. 질문 상태와 실제 답변 연결이 다른 경우 둘을 같은 지표로 취급한다.

## 4. AI 전 단계에서 강사에게 제공할 데이터 분석

### 4.1 개별 강의자료 분석

| 분석 항목 | 계산 방법 | 강사에게 주는 의미 |
| --- | --- | --- |
| 근거 범위 | 전체 슬라이드 수, 유효 질문이 있는 슬라이드 수, 질문이 없는 슬라이드 수 | 리포트가 자료 전체를 얼마나 대표하는지 보여준다. |
| 질문 상태 | 목적별 유효 질문을 기준으로 상태별 개수와 비율을 다시 계산 | 질문 처리 현황을 보여준다. |
| 실제 답변 범위 | 답변 레코드가 하나 이상 연결된 질문 수 / 유효 질문 수 | 상태값과 별개로 실제 답변 존재 여부를 보여준다. |
| 슬라이드 과밀 지점 | 슬라이드별 유효 질문, 미답변, 공감 수를 각각 표시 | 질문이 많이 몰린 슬라이드를 찾는다. |
| 공간 집중도 | PIN의 정규화 좌표를 격자에 투영하여 점유 셀과 셀별 질문 분포를 계산 | 슬라이드 전체가 막힌 것인지 특정 그림·수식·문장이 막힌 것인지 구분한다. |
| 질문 종류 | 강사가 설정한 질문 범주별 개수와 비율 | 개념, 오류, 예시 요청 등 대응 종류를 나눈다. |
| 반복 주제 | 서로 다른 슬라이드의 검증된 하위 주장이 같은 의미를 지지하는지 확인 | 한 장의 문제가 자료 전체에서 반복되는지 판단한다. |
| 모순 쟁점 | 같은 주제의 하위 주장 사이에 모순 관계가 있는지 확인 | AI가 다수 의견 하나로 덮지 않고 강사 확인 항목으로 올린다. |

`공간 집중도`는 이해도 점수가 아니다. `실제 답변 범위`도 학습 성취도가 아니다. 현재 데이터만으로 말할 수 있는 것은 질문·반응·답변의 관찰 결과다.

### 4.2 폴더 기반 분석

| 분석 항목 | 계산 방법 | 강사에게 주는 의미 |
| --- | --- | --- |
| 자료 근거 범위 | 선택 자료 수, 질문이 있는 자료 수, 질문이 없는 자료 수 | 폴더 결론의 대표 범위를 보여준다. |
| 전체 수치 | 모든 자식 자료의 분자와 분모를 합친 뒤 비율을 다시 계산 | 자료별 퍼센트의 단순 평균 오류를 막는다. |
| 자료별 분포 | 자료별 질문 수·미답변 수·근거 범위의 중앙값과 범위 | 큰 자료 하나가 전체를 가리는지 보여준다. |
| 자료 편중도 | 특정 주제 또는 전체 질문 중 가장 큰 자료가 차지하는 비율 | 폴더 결론이 한 자료에 종속됐는지 보여준다. |
| 자료 간 반복 주제 | 같은 주제를 지지하는 서로 다른 자료 수를 계산 | 진짜 폴더 공통 신호와 자료 하나의 신호를 구분한다. |
| 자료 간 모순 | 서로 다른 자료의 검증된 주장 사이의 지지·모순·무관 관계를 판정 | 자료마다 다른 설명이나 질문 경향을 숨기지 않는다. |
| 근거 부족 | 자료 수, 유효 질문 수, 질문 있는 자료 수가 기준보다 적은지 계산 | 폴더 전체라는 표현을 제한한다. |

폴더는 정리용 컨테이너다. 같은 폴더에 들어 있다는 사실만으로 자료들이 같은 내용을 다룬다고 가정하지 않는다. 자료 간 공통 주제는 의미 관계를 별도로 검증해야 한다.

### 4.3 개선 우선순위 표시

불투명한 단일 `AI 점수`는 만들지 않는다. 각 개선 항목에 다음 이유를 함께 붙여 정렬한다.

- 영향을 받은 서로 다른 자료 수
- 영향을 받은 서로 다른 슬라이드 수
- 유효 질문 수
- 미답변 질문 수
- 공감 수
- 자료 편중도
- 모순 존재 여부
- 근거 수준과 필터 제외 수

공감은 신호의 강도를 보조하지만 독립 근거 수를 늘리지 않는다. 질문 100개가 한 슬라이드에 몰린 경우 `강한 국소 신호`가 될 수 있지만 `넓은 범위의 공통 신호`로 자동 승격하지 않는다.

## 5. CP-04의 구체 처리 알고리즘

### 단계 1. 분석 범위와 기준 시각 고정

강사가 자료 하나, 여러 자료 또는 폴더 전체를 선택하면 서버가 소유권과 폴더 소속을 확인한다. 하나의 DB transaction에서 기준 시각을 정하고 선택 범위의 자료, 슬라이드, PIN 좌표, 질문, 답변, 공감을 일괄 snapshot으로 복사한다. 외부 AI 호출은 transaction에 넣지 않는다.

### 단계 2. 외부 AI용 별칭과 원본 계보 생성

자료·슬라이드·질문에 snapshot 안에서만 유효한 순번 별칭을 부여한다. 실제 UUID와 별칭의 대응표는 서버에만 보존한다. snapshot hash, 선택 순서, 원본 이미지 checksum과 분석 정책 버전을 기록한다.

### 단계 3. 목적별 유효 질문 결정

CP-02의 질문 적격성 처리로 각 질문을 `분석 사용`, `제외`, `검토 필요`로 구분하고 이유를 기록한다. 한 질문에 전역 `invalid` 값 하나를 영구 저장하지 않는다. 자료 이해 분석, 진행 분석, 공개 요약은 목적이 다르므로 사용 가능 여부도 다를 수 있다.

### 단계 4. 슬라이드 근거 노드 생성

코드가 질문 수, 상태, 실제 답변 유무, 공감, 범주와 좌표 분포를 계산한다. AI는 슬라이드 이미지·좌표 주변 crop·질문을 이용해 하위 주장을 구조화된 형식으로 만든다. 각 주장은 질문 참조, 좌표 참조, metric 참조와 지지·모순 관계를 가진다. 코드 검증과 별도 AI 비평을 통과한 결과만 다음 단계로 보낸다.

### 단계 5. 강의자료 수준으로 승격

서로 다른 슬라이드의 하위 주장 가운데 의미가 같은 후보만 비교한다. 지지 관계를 edge로, 모순 관계를 별도 edge로 기록한다. 상위 주장은 다음 조건에 따라 분류한다.

- 서로 다른 슬라이드 두 개 이상에서 지지되면 `자료 반복 신호` 후보가 된다.
- 한 슬라이드에서만 지지되면 `슬라이드 국소 신호`로 유지한다.
- 지지 집합 안에 모순 관계가 있으면 충분한 반복 결론으로 승격하지 않고 쟁점으로 표시한다.
- 질문 수가 많아도 서로 다른 슬라이드 수를 대신할 수 없다.

자료 합계와 비율은 하위 퍼센트를 평균하지 않고 원래 분자·분모에서 다시 계산한다.

### 단계 6. 폴더 또는 복수 자료 수준으로 승격

검증된 자료 주장만 상위 입력으로 사용한다. 서로 다른 자료의 주장 관계를 지지·모순·무관으로 검증한다.

- 서로 다른 자료 두 개 이상에서 지지되면 `자료 간 반복 신호` 후보가 된다.
- 한 자료에서만 지지되면 폴더 리포트에 포함할 수는 있지만 `특정 자료 신호`라고 표시한다.
- 가장 큰 자료의 질문 비중과 지지 자료 수/선택 자료 수를 함께 계산한다.
- 지지 자료가 둘 이상이어도 한 자료에 질문이 과도하게 몰리면 `자료 간 존재하나 편중됨`으로 표시한다.
- 모순 관계를 공감 수나 다수결로 없애지 않는다.

### 단계 7. 상위 AI 입력 제한

자료 수준 AI에는 검증된 슬라이드 주장과 코드 metric만, 폴더 수준 AI에는 검증된 자료 주장과 코드 metric만 보낸다. 상위 AI에 원본 질문이나 이미지를 다시 주어 새로운 해석을 만들게 하지 않는다. 수치는 값 자체가 아니라 metric 식별자로 쓰게 하고, 최종 렌더러가 검증된 값으로 치환한다.

### 단계 8. 범위 일관성 검증과 저장

코드는 각 상위 문장이 실제 하위 주장, 서로 다른 자식 단위 수, metric과 모순 기록을 참조하는지 확인한다. `폴더 공통`, `자료 반복`, `슬라이드 국소`, `근거 부족`, `편중됨`, `모순 있음` 같은 범위 표지가 검증 결과와 맞지 않으면 전체 후보를 거부한다. 통과한 claim graph와 리포트 표현을 고정 snapshot에 저장한다.

## 6. DB 구조와 AI 입력의 연결

현재 원본 데이터 경로는 다음과 같다.

```text
session_folders
  └─ courses
      └─ lectures
          └─ materials
              └─ material_versions  ← 업로드 원본 식별용이며 개정 비교 기능이 아님
                  └─ slides
                      ├─ region_anchors ─ questions ─ answers
                      └─ questions ─ question_reactions
```

기존에 설계된 여섯 리포트 테이블을 그대로 활용할 수 있다.

| 저장 위치 | CP-04에서 추가로 맡을 정보 |
| --- | --- |
| `ai_reports` | 선택 범위, 기준 시각, 정책/hash, 전체 deterministic metric, 폴더·복수 자료 claim graph, canonical 결과 |
| `ai_report_materials` | 자료별 분자·분모, 분포, 편중 지표, 자료 수준 claim, 자식 slide claim 참조 |
| `ai_report_slides` | 질문 snapshot, 목적별 적격성, 좌표·crop, 슬라이드 metric, slide claim과 질문 참조 |
| `ai_report_revisions` | 같은 claim 집합을 사용한 표현 변경과 검증 결과 |
| `ai_report_jobs` | snapshot, slide 분석, 자료 합성, 폴더 합성, 검증 작업 상태 |
| `ai_report_storage_cleanup` | 비식별화 근거 이미지의 삭제 outbox |

첫 구현부터 별도 graph DB나 `ai_report_claims` 테이블을 추가할 필요는 없다. 각 수준의 versioned JSONB에 다음 논리 필드를 두면 된다.

```text
claim_id
scope_level                 slide | material | selection/folder
scope_alias
child_claim_refs
supporting_question_refs
opposing_question_refs
metric_refs
distinct_child_count
selected_child_count
concentration_ratio
relation_verdicts
evidence_level
scope_label
```

`course_brain_memory`는 AI 입력의 권위 원본으로 사용하지 않는다. 현재 질문/답변 insert를 복사하는 보조 메모리이고 질문 수정과 완전히 동기화되지 않을 수 있으므로, 리포트 snapshot은 원본 관계형 테이블에서 직접 만들어야 한다.

## 7. CP-02와 CP-04의 경계

| 구분 | CP-02 | 새 CP-04 |
| --- | --- | --- |
| 중심 질문 | 이 질문과 질문 관계가 결론의 근거로 유효한가? | 유효한 하위 결론을 자료·폴더 수준으로 올려도 되는가? |
| 주 처리 방향 | 같은 슬라이드 안의 공간·의미 검증 | 질문→슬라이드→자료→폴더의 수직 승격 |
| 독립 근거 | 서로 다른 질문 레코드 | 범위에 따라 질문, 슬라이드, 자료로 전환 |
| 대표 오류 | 무관·유해·모순 질문을 같은 혼란으로 묶음 | 한 슬라이드나 한 자료의 대량 질문을 전체 패턴으로 확대 |
| 출력 제어 | 결론 허용·보류와 근거 수준 | 국소·자료 반복·폴더 반복·편중·모순 범위 표지 |

CP-04는 CP-02의 검증 결과를 사용할 수 있지만, 질문 필터와 같은 슬라이드 관계 판정 자체를 다시 권리화하는 후보는 아니다.

## 8. 청구항으로 잡을 중심

독립항의 중심 조합은 다음과 같이 잡는다.

1. 선택 범위의 관계형 계층과 PIN 질문 데이터를 기준 시각으로 고정하는 단계
2. 검증된 질문 근거로 슬라이드 수준 주장을 만드는 단계
3. 분석 범위에 따라 독립 근거 단위를 질문, 슬라이드, 자료로 전환하는 단계
4. 지지·모순 관계와 서로 다른 자식 단위 수에 따라 하위 주장을 상위 주장으로 승격하거나 하위 범위에 유지하는 단계
5. 상위 수치를 하위 비율 평균이 아닌 분자·분모 재집계로 생성하는 단계
6. 자식 단위의 근거 범위와 최대 기여 비율로 자료 편중을 계산하여 상위 범위 표지 또는 근거 수준을 제한하는 단계
7. 상위 AI가 검증된 자식 주장과 metric 참조만 사용하도록 입력을 구성하는 단계
8. 생성 문장의 하위 claim·metric·범위 표지를 검증하고 결과를 고정 snapshot에 저장하는 단계

종속항 후보는 좌표 격자 집중도, 공감의 비독립 근거 처리, 모순 시 승격 제한, 목적별 질문 적격성, 외부용 별칭, metric 값의 렌더 시 치환, 코드 검증 후 별도 AI 비평, 자료별/폴더별 A·B 표현 재사용이다.

단순한 테이블 배열, `DB 데이터를 AI에 넣는다`, `자료별로 요약한 뒤 폴더로 요약한다`는 표현을 독립 발명으로 내세우지 않는다.

## 9. 선행기술과의 거리

다음 넓은 개념은 이미 알려져 있어 그대로는 약하다.

- 발표·강의의 구간별 반응을 분석해 강사에게 리포트와 개선 정보를 제공하는 기술: [US20240161647A1](https://patents.google.com/patent/US20240161647A1/en), [US20150347560A1](https://patents.google.com/patent/US20150347560A1/en)
- 문서별 요약을 만든 뒤 여러 문서의 상위 요약을 만드는 기술: [US20240281487A1](https://patents.google.com/patent/US20240281487A1/en)
- 여러 독립 출처의 수가 임계값을 넘을 때 사실을 채택하는 기술: [US8682913B1](https://patents.google.com/patent/US8682913B1/en)
- AI 생성 문서를 원본 chunk와 추적 가능하게 연결하는 기술: [US12511301B1](https://patents.google.com/patent/US12511301B1/en)

따라서 CP-04의 차별 후보는 다음 결합에 있다.

- 강의자료의 공간 PIN 질문을 최하위 근거로 사용한다.
- 선택 범위가 슬라이드·자료·폴더로 커질 때 독립 근거 단위를 동적으로 바꾼다.
- 질문량과 공감량이 많아도 서로 다른 자식 단위 수를 대체하지 못한다.
- 각 수준의 지지·모순 graph를 통과한 claim만 상위 AI 입력으로 승격한다.
- 전체 수치의 분모를 다시 계산하고 자료 편중에 따라 범위 표현을 자동 제한한다.
- 상위 AI는 원본을 재해석하지 않고 검증된 하위 claim과 metric만 사용한다.

이 결합도 신규성·진보성이 확정된 것은 아니다. 국내외 정밀 검색에서 청구항 요소별로 다시 대조해야 한다. 지식재산 당국은 AI의 단순 적용보다 입력 데이터, 전처리, 모델과 출력의 구체적 관계 및 그 차이로 생기는 효과를 명세서에 적을 것을 요구한다. [공식 AI 발명 안내](https://www.kipo.go.kr/ko/kpoContentView.do?menuCd=SCD0201244)

## 10. 구현·검증 과제

출원 명세서의 실시 가능성과 제품 효과를 뒷받침하려면 다음 fixture가 필요하다.

1. 한 슬라이드에 같은 질문 100개, 다른 슬라이드에는 질문 없음
2. 같은 주제가 서로 다른 슬라이드 두 곳에 존재
3. 같은 주제가 한 자료에만 존재하고 폴더의 다른 자료에는 없음
4. 같은 주제가 서로 다른 자료 두 개에 존재하나 한 자료에 95% 편중
5. 자료 간 의미가 유사해 보이지만 실제로는 무관한 주장
6. 서로 다른 자료가 같은 주제에 반대되는 질문을 포함
7. 질문 필터 변경으로 지지 자료 수가 둘에서 하나로 감소
8. 자료별 비율의 평균과 전체 분자·분모 재계산 값이 다른 사례
9. 질문 상태는 해결됨이지만 답변 레코드는 없는 사례와 그 반대 사례
10. 질문이 없는 자료가 다수 포함된 폴더

비교 평가는 `AI에 원본 전체를 한 번에 전달`, `자료별 요약 후 자유 합성`, `질문 수만으로 상위 패턴 판정`을 기준선으로 두고, 범위 과장, 수치 불일치, 모순 은폐, 근거 추적 실패, 자료 편중 오판의 비율을 측정한다.

## 11. 이번 결정

- 기존 CP-04 개정판·측정조건 비교는 최종 후보에서 제외한다.
- DB 구조 자체는 독립 후보로 내지 않는다.
- DB snapshot, 계층별 claim 기록, deterministic metric과 AI 입력 제한은 새 CP-04의 구체 실시 수단으로 사용한다.
- 현재 데이터만으로 `학습효과`나 `강의 효용성`을 수치화하지 않는다. 현재 제공 가능한 것은 질문·공간·답변·반응에 근거한 강의 분석과 개선 신호다.
- 학습효과를 나중에 제공하려면 별도의 평가 문항, 노출 분모, 사전·사후 또는 후속 수행 데이터가 필요하며 이번 특허 후보의 전제가 아니다.
