# AI 강의자 리포트 제품 명세

- Artifact: `ai-report-product`
- Status: `reviewed`
- Source: `doc/pin_class_prd.md`
- Decision boundary: 강사의 리포트 선택, 생성, 검토, AI 수정, 확정, 근거 표시, PDF 전달 경험

## 1. 목적과 제품 경계

- `AIR-PROD-001` 강사는 자신이 소유한 자료 한 개, 여러 개 또는 폴더 전체를 선택해 강의 개선 리포트를 생성할 수 있어야 한다.
- `AIR-PROD-002` 리포트는 강의 자료 이미지와 해당 자료의 PIN, 좌표, 질문, 상태, 답변, 반응을 기반으로 작성해야 한다.
- `AIR-PROD-003` 기존에 업로드된 자료도 재업로드 없이 분석할 수 있어야 한다.
- `AIR-PROD-004` 근거 기반 개선 리포트 A형과 서술형 B형은 동일한 분석 결과를 서로 다른 표현으로 보여줘야 하며, 전환할 때 AI를 다시 호출하지 않는다.
- `AIR-PROD-005` 리포트는 강사를 위한 의사결정 초안이며 질문 상태나 강의 자료를 자동으로 변경하지 않는다.
- `AIR-PROD-006` 모든 생성과 AI 수정은 백그라운드에서 처리되며 사용자는 화면을 떠났다가 돌아올 수 있다.

첫 버전은 다음 기능을 포함하지 않는다.

- 수강생 대상 AI 답변
- 공개 리포트 링크와 이메일 전송
- speaker note 분석
- 강사의 직접 본문 편집
- Course Brain 또는 RAG 검색
- AI에 의한 질문 상태나 강의 자료의 자동 변경

## 2. 사용자와 접근 권한

- `AIR-PROD-010` 로그인한 강의 자료 소유자만 리포트를 생성, 조회, 수정 요청, 확정, 다운로드할 수 있어야 한다.
- `AIR-PROD-011` 익명 수강생과 다른 강사의 계정에는 리포트 목록과 내용이 노출되지 않아야 한다.
- `AIR-PROD-012` 확정 전 초안은 서비스 내부에서만 확인할 수 있으며 다운로드할 수 없다.
- `AIR-PROD-013` 확정된 revision만 PDF로 다운로드할 수 있다.
- `AIR-PROD-014` 조직 관리자, 공동 강사, 공개 공유 권한은 첫 버전에 포함하지 않는다.

## 3. 진입과 자료 선택

- `AIR-PROD-020` 리포트 생성은 폴더 상세의 `Insights` 탭에서 시작한다.
- `AIR-PROD-021` 한 화면에서 자료 한 개, 여러 개 또는 폴더 전체를 선택할 수 있어야 한다.
- `AIR-PROD-022` 별도의 리포트 생성 화면이나 라이브 플레이어용 중복 버튼은 만들지 않는다.
- `AIR-PROD-023` 생성 요청 시점의 자료 버전과 PIN 데이터를 분석 대상으로 고정한다.
- `AIR-PROD-024` 자료 또는 PIN이 없는 항목도 선택할 수 있지만, 생성 전 근거 부족 가능성을 표시한다.

## 4. 생성 전 확인

- `AIR-PROD-030` 생성 전 선택 자료 수, 슬라이드 수, PIN 수와 예상 비용 범위를 표시한다.
- `AIR-PROD-031` 설정된 비용 임계값을 넘는 경우에만 추가 확인을 받아야 한다.
- `AIR-PROD-032` 임계값을 넘더라도 자료를 임의로 제외하거나 부분 리포트를 만들지 않는다.
- `AIR-PROD-033` 생성 버튼을 반복 클릭해 같은 요청이 중복 생성되지 않아야 한다.

## 5. 생성 상태

- `AIR-PROD-040` 사용자에게 `대기 중`, `분석 중`, `검토 가능`, `실패`, `확정` 상태를 명확하게 표시한다.
- `AIR-PROD-041` 생성 중 페이지를 떠나도 작업이 계속되어야 한다.
- `AIR-PROD-042` 다시 방문하면 현재 상태와 완료된 결과를 확인할 수 있어야 한다.
- `AIR-PROD-043` 실패 시 기존 선택을 유지한 상태로 다시 시도할 수 있어야 한다.
- `AIR-PROD-044` 재시도는 새 리포트를 만들지 않고 같은 생성 요청을 복구해야 한다.

## 6. 리포트 구성과 A/B 보기

- `AIR-PROD-050` 리포트 머리말에는 선택 범위, 자료 버전, 데이터 기준 시각, 현재 revision, 전체 근거 수준을 표시한다.
- `AIR-PROD-051` 공통 분석 결과는 핵심 요약, 주요 혼란 지점, 미답변 질문, 개선 우선순위, 자료별 상세를 포함한다.
- `AIR-PROD-052` A형은 결론과 근거를 빠르게 대조할 수 있는 근거 중심 카드 형식으로 보여준다.
- `AIR-PROD-053` B형은 강사에게 전달할 수 있는 서술형 리포트 형식으로 보여준다.
- `AIR-PROD-054` A형과 B형 전환은 즉시 이루어져야 하며 추가 AI 호출이나 비용이 발생하지 않는다.
- `AIR-PROD-055` 두 형식의 사실, 수치, 결론, 근거는 서로 일치해야 한다.

## 7. 근거와 좌표 표시

- `AIR-PROD-060` 모든 분석 문장과 주요 결론은 해당 슬라이드와 PIN 근거로 이동할 수 있어야 한다.
- `AIR-PROD-061` 근거를 선택하면 전체 슬라이드, PIN 좌표 오버레이, 좌표 주변 영역, PIN 본문을 함께 확인할 수 있어야 한다.
- `AIR-PROD-062` 근거 수준은 `충분`, `제한적`, `불충분`으로 구분하고 리포트, 섹션, 결론 단위로 표시한다.
- `AIR-PROD-063` 관련 PIN이 2개 미만이면 PIN 기반 결론을 단정하지 않고 자료 요약과 근거 부족 안내만 제공한다.
- `AIR-PROD-064` 좌표가 없는 슬라이드 전체 질문은 `좌표 없음`으로 명시한다.
- `AIR-PROD-065` 근거 화면과 리포트에는 수강생 식별자, 이메일, 세션 정보, speaker note를 포함하지 않는다.
- `AIR-PROD-066` PDF에서도 자료명, 슬라이드 번호, PIN 인용을 사람이 이해할 수 있는 형태로 표시한다.

## 8. AI 수정 요청과 revision

- `AIR-PROD-070` 강사는 전체 리포트 또는 특정 섹션을 지정해 자연어로 AI 수정 요청을 보낼 수 있어야 한다.
- `AIR-PROD-071` 수정 요청은 동일한 데이터 snapshot을 사용해 새 revision을 만든다.
- `AIR-PROD-072` 수정 중에도 이전 revision을 계속 조회할 수 있어야 한다.
- `AIR-PROD-073` 한 리포트에는 동시에 하나의 수정 요청만 실행하며 중복 요청을 방지한다.
- `AIR-PROD-074` AI 수정에도 최초 생성과 같은 비용 임계값 정책을 적용한다.
- `AIR-PROD-075` 최초 초안과 각 revision에는 수정 지시와 생성 시각을 표시한다.
- `AIR-PROD-076` 수정에 실패해도 현재 사용 가능한 revision을 유지한다.
- `AIR-PROD-077` 강사는 성공한 revision 중 하나를 선택해 확정할 수 있어야 한다.
- `AIR-PROD-078` 직접 본문 편집과 별도의 diff UI는 첫 버전에 포함하지 않는다.

## 9. 확정, 새 데이터, PDF

- `AIR-PROD-080` 리포트에는 분석에 사용한 자료 버전과 데이터 기준 시각을 표시한다.
- `AIR-PROD-081` 데이터 기준 시각 이후 선택한 자료, PIN, 답변 또는 반응이 변경되면 `새 데이터 있음`을 표시하되 기존 리포트와 revision은 변경하지 않는다.
- `AIR-PROD-082` 강사가 새 데이터로 다시 생성하면 같은 선택 범위를 사용해 새 리포트 버전을 만들고 생성 전 확인을 다시 거친다.
- `AIR-PROD-083` 동일한 근거 snapshot의 표현을 변경하는 revision과 새로운 근거 snapshot을 사용하는 리포트 버전을 UI에서 명확히 구분한다.
- `AIR-PROD-084` 강사가 성공한 revision 하나를 확정하면 해당 리포트 버전은 변경할 수 없는 상태가 된다.
- `AIR-PROD-085` 확정된 리포트에는 추가 AI 수정 요청을 보낼 수 없다.
- `AIR-PROD-086` 확정된 revision만 PDF로 다운로드할 수 있다.
- `AIR-PROD-087` 동일한 확정 revision에서 A형과 B형 PDF를 추가 AI 호출 없이 생성할 수 있어야 한다.
- `AIR-PROD-088` 초안과 확정 리포트의 서비스 내 조회에는 소유자 인증이 필요하며 공개 URL이나 이메일 전송 기능을 제공하지 않는다.

## 10. 오류, 접근성, 인수 조건

- `AIR-PROD-090` 생성과 수정 실패 시 내부 오류나 AI 제공자 정보를 노출하지 않고 사용자가 실행할 수 있는 재시도 방법을 안내한다.
- `AIR-PROD-091` 생성 또는 수정 실패가 마지막으로 사용할 수 있었던 결과를 덮어쓰지 않아야 한다.
- `AIR-PROD-092` 자료 선택, A/B 전환, revision 선택, 근거 열람, 확정, PDF 다운로드를 키보드로 조작할 수 있어야 하며 각 컨트롤에 명확한 accessible name과 focus-visible 상태를 제공한다.
- `AIR-PROD-093` 백그라운드 상태 변경은 방해하지 않는 live region으로 알리고 `Saving...`과 같은 차단 팝업을 표시하지 않는다.
- `AIR-PROD-094` 근거 상세 창은 키보드로 닫을 수 있어야 하고 닫은 뒤 실행한 컨트롤로 포커스를 돌려준다.
- `AIR-PROD-095` 출시에 앞서 단일 자료, 복수 자료, 폴더 전체 선택과 생성 전 확인, 비용 임계값 추가 확인, 페이지 이탈 후 복귀, A/B 무호출 전환, 좌표 근거 열람, 근거 부족 시 판단 보류, 섹션 및 전체 AI 수정, revision 보존, 새 데이터 재생성, 확정과 PDF 다운로드 흐름을 검증한다.
- `AIR-PROD-096` 유효한 원본 근거로 이동할 수 없는 분석 문장이나 주요 결론은 출시 차단 오류로 취급한다.
- `AIR-PROD-097` 익명 수강생과 다른 강사가 리포트 목록, 내용, 근거, PDF에 접근할 수 없어야 한다.
