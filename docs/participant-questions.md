# Participant question visibility

Participants can hide/show their own question panel through an always-available header button. Default is visible. This is local UI state, not instructor permission or a shared setting. Preserve existing current-slide public questions, statuses, instructor answers, sort order, empathy rules and realtime subscription while hidden. Hide only the panel; never delete questions, alter other participants' views or disconnect live updates. Restore the current question list when reopened. No persistence or database changes.
