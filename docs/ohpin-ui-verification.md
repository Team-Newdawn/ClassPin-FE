# OhPin UI 개편 검증 기록

## 업로드·자료 UI 후속 보정 (2026-10-02)

사용자가 지정한 업로드 `161:5934`, 카드 `161:5878`, 목록 `161:6307`을 반영했다. 카드 썸네일 높이 170px, 업로드 너비 580px, 파일별 용량·완료 슬라이드 수, 목록의 고정 열과 폴더 내 업로드 버튼을 적용했다. 버튼은 ‘강의준비’·‘강의시작’으로 통일했다. 마지막 강의 시각은 API에서 제공하지 않아 ‘—’로 표시한다.

파일 선택 즉시 변환하는 기존 정책을 유지한다. 저장할 폴더는 파일 선택 전에 지정하며, 선택 후에는 고정한다. 파일 행 숨기기는 이미 만들어진 자료를 삭제하지 않는다. 변환 진행률이 제공되지 않는 단계는 임의의 수치 대신 indeterminate progress로 표시한다.

PDF 두 개의 즉시 변환과 완료 표시, 추가 PDF의 정상 생성, 행 숨기기 후 실제 자료 보존, 한국어·영어 버튼, 카드/목록 전환, 목록 메뉴가 스크롤 영역 밖에서도 보이는 것을 브라우저에서 확인했다. 1440px 카드/목록과 375px 업로드 화면을 확인했다. 최종 린트·빌드·25개 관련 테스트가 통과했다. 새 의존성은 없다. 검증용 자료만 제거했다.

검증일: 2026-10-02. 기준: `docs/ohpin-figma-ui-redesign.md`의 사용자 승인 범위.

## 구현 범위

- Figma 색상·타이포그래피·크기 토큰, 로고와 아이콘을 공용 디자인 시스템으로 적용했다. 기존 폴더 색상 인덱스는 보존하고 새 팔레트로 표시한다.
- 로그인/가입 안내, 폴더 홈, 자료 목록, 업로드, 준비 화면, 강사 LIVE/발표, 청중 질문 화면, 간단한 종료 리포트를 개편했다.
- 파일 선택 즉시 순차 업로드·변환한다. 파일별 진행·실패·재시도를 표시하고 실패 뒤에도 다음 파일을 처리한다. 기존 업로드 크기 검증과 Storage 경계를 유지한다.
- 강사 답변·해결 UI를 제거했다. 과거 저장 데이터와 청중 본인 질문 수정 권한 검증은 보존했다.
- 가까운 PIN을 묶고 다른 PIN만 약하게 표시한다. 자동 발표 스위치 하나로 순차 노출·자동 이동·새 질문으로 이동을 함께 제어한다.
- 폴더 목적, 폴더 내부 인사이트/범위 선택, 한국어·영어, 발표자 노트, 슬라이드 이동, 패널 접기·크기 조절을 유지한다.
- 종료 확인 뒤 간단한 리포트로 이동한다. 현재 자료의 전체 질문을 집계하며 회차별 통계로 표시하지 않는다. 삭제된 슬라이드의 질문과 최다 질문 동률도 집계한다.

## 확인한 근거

- 로컬 Docker/Supabase 시작 및 `npm run supabase:reset`: 전체 마이그레이션 재생 성공. 이번 변경에는 스키마 변경이 없다.
- `npx eslint . -f json`, `npm run build`, `git diff --check`: 성공.
- Node 내장 테스트: PIN 묶음, 발표 순환, 폴더 색상, 참여자 질문 권한, 공감, 번역 키, 리포트 집계의 25개 테스트 성공.
- 문서 context lock/context pack 검증 성공.
- 로컬 데모 브라우저에서 로그인 이동, 가입 안내, 언어 전환, 폴더/자료 그리드·목록 전환, 폴더 인사이트를 확인했다.
- 실제 테스트 PDF 업로드·변환·자료 생성과 잘못된 파일 뒤 다음 PDF의 성공을 확인했다.
- 준비 화면, 노트 저장, 방향키 슬라이드 이동, 패널 크기 조절 핸들러, 자동 발표 켜기/끄기, PIN 묶음, 종료 확인 후 리포트 이동을 확인했다.
- 청중 본인 질문 수정 저장, 전체 질문에서 다른 슬라이드 질문 선택, 375px 화면을 확인했다.
- Ponytail ultra 최종 검토: 새 의존성 없이 native details와 브라우저 인쇄를 사용했다. 퇴역한 답변/해결 제어와 PIN 위치 강제 이동 표시 코드 등 사용하지 않는 코드를 제거했다.

## 남은 연결 및 검증

- **실제 AI 요약은 연결되지 않았다.** 리포트 컴포넌트는 요약 입력을 받을 수 있지만 현 저장소에 종료 리포트용 AI API가 없어 미연결 상태를 명시한다. 상세 AI 리포트와 별도 기능이다.
- 회차 분리, 시작 전 대기 상태, 다른 자료로 이동한 뒤 5분 자동 종료는 사용자 결정에 따라 이번 프런트엔드 범위에서 제외했다.
- 제출 질문 삭제는 REST API 배포 이후 작업이다. 질문 작성 중 PIN 취소만 유지한다.
- OAuth 로그인 후 실제 REST/Storage/Realtime의 강사·청중 동시 E2E, 운영 배포, 실제 AI 생성은 검증하지 않았다.
- PDF 내보내기는 브라우저 인쇄 기능을 사용한다. 네이티브 인쇄 대화상자에서 실제 파일 저장은 검증하지 않았다.
- 브라우저 확인은 별도 3001 포트의 데모 모드에서 수행했다. 검증용으로 만든 자료만 제거하며 기존 사용자 자료는 보존한다.

## 폴더 그리드·리스트 후속 보정 (2026-10-02)

사용자 지정 `161:4962` 및 `161:6090`의 디자인 context·스크린샷·레이어 치수를 확인했다. 카드 높이 212px, 28px 메뉴, 종이와 포켓 레이어, 집계·시각을 반영했다. 리스트는 65px 행, 36px 색상 아이콘, 18px 원본 SVG, 네이티브 표·정렬 선택·새 폴더 만들기 행으로 구현했다. 미분류는 Slate다. 업데이트 문구와 정렬은 실제 폴더 생성·자료 추가 시각을 기준으로 하며 도움말로 그 범위를 밝힌다.

- 검증 폴더 두 개를 그리드/리스트 삭제 UI로 제거했다. 테스트의 네이티브 삭제 확인은 true로 대체했고 실제 확인 창 조작은 재검증하지 않았다. 원래 폴더 2개와 자료 2개를 보존했다.
- Ponytail ultra review: 기존 단일 카드·집계·시간 포맷·네이티브 표/선택/details를 재사용했다. 사용하지 않는 createTile CSS를 삭제했고 추가 추상화·의존성은 없다.
- 로컬 `supabase:start`, 깨끗한 `supabase:reset`, `npm run lint`, `npm run build`, 폴더·i18n·집계 Node 테스트 8개, diff check가 통과했다. 인증 REST/운영 환경 E2E는 이번 UI 보정의 검증 범위 밖이다.
