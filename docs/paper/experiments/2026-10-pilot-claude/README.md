# 예비 실험 (Claude 단독, 2026-10-21)

- 스크립트는 실행 당시 그대로 보관했다(제품 `node_modules` 절대 경로를 import). 재실행용이 아니라 기록용이다.
- 슬라이드 원본·렌더 이미지는 `data/`(git 제외). 실제 덱은 저자 소유 피치덱(15쪽)이다.
- 결과 수치는 `results/*.json`을 다시 집계한 값이다.

## P1: PIN 위치 대응 (`location/`)

- 모델: `claude-haiku-5-5`, `effort: low`, 구조화 출력(JSON schema). 채점: `claude-sonnet-5-5`(`effort: medium`)가 자유 서술 답과 정답 라벨을 비교.
- 이미지: 1456×819 PNG(축소 없음). PDF: 해당 쪽만 잘라 `document` 블록으로 전송.
- 조건
  - A: PDF + 정수 % 좌표(`Math.round`, 가로 1% ≈ 14.5px)
  - B: 이미지 + 정확한 픽셀 좌표
  - C: 원본 이미지 + 번호 표시 이미지 + 픽셀
  - D: C + zoom 도구(원본 2배 해상도에서 잘라 확대)
  - E: 원본 이미지 + 점만 표시한 이미지 + 픽셀
- 쉬운 조건(`pins.json`, 22~36 PIN, 1회): A·C 모두 100%.
- 어려운 조건(`pins-hard.json`, `gen2.py`): 2쪽 70 PIN, 10쪽 100 PIN. 요소 영역 안 무작위 위치, 일부 영역에 가중치(몰림). 질문 문장은 일반 문장 8종에서 무작위.

| 조건 | 2쪽(70 PIN, 4회) | 10쪽(100 PIN, 4회) | 평균 입력 토큰(2쪽) |
|---|---|---|---|
| A | 72.1% (202/280) | 96.0% (384/400) | 4,482 |
| B | 95.4% (267/280) | 98.3% (393/400) | 4,520 |
| C | 95.7% (268/280) | 99.3% (397/400) | 5,541 |

- 별도 2회 실행에서 D 96.4%/100%, E 93.6%/97.0%. D의 zoom 호출은 0회.
- A는 실행 간 편차가 컸다(2쪽 첫 2회 평균 90.0%, 4회 평균 72.1%).
- 한계: A·B는 좌표 정밀도와 입력 형태가 섞였다(`../../research/critique-and-risks.md`).

## P2: 글자 판독 (`text-reading/`)

- 모델: `claude-haiku-5-5`, `effort: low`. 채점: 공백·따옴표 정규화 후 완전 일치(자동).
- 세트: 합성 PDF 4쪽(`synth.pdf`, 표·작은 글자, 43문항), 실제 덱 2쪽(각주·작은 회색 글자, 10문항). 3회 반복(아래 분모는 3회 합계).
- 조건: PDF, IMG(이미지만), IMG+TXT(읽기 비율 0.9 이상일 때 텍스트 첨부), IMG+TXT-raw(필터 없이 첨부).
- 결과: PDF·IMG+TXT 전 세트 100%. IMG는 합성 1쪽 97.1%(67/69), 3쪽 93.3%(14/15), 나머지 100%.
- 해석: Claude PDF 입력은 내부적으로 이미지+텍스트이므로 PDF = IMG+TXT는 구조상 예상되는 결과다.
