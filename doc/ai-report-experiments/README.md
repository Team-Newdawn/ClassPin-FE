- **환경:** Core Ultra 5 125H·RAM 16GB급·CPU 4스레드·GPU 미사용·LLM Q4_K_M. 후보별 1회.
- **품질 평가:** OCR=3페이지 24문구, 영역=IoU 0.5 이상인 8개 부분 정답, 의도=비블라인드 임시 라벨. 의미 정확도·상용 성능을 확정한 결과가 아닙니다.
- **비용:** 동일 성능 worker 시간당 1,000원 가정. 실제 청구액이 아니며 변환·설치·저장·유휴·운영비 제외.
- **범위:** S·Florence는 영역 분석 후 리포트 단계 제외. EasyOCR는 색상 입력 오류 수정 후 재실행한 결과.
- **근거:** 로컬 `output/model-benchmark-final-v1/` (데이터 미게시). 공개 모델도 운영비와 라이선스 준수 검토가 필요합니다.
